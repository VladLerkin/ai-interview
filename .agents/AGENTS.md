# AI Interview Simulator Agent Guidelines

- **Build Verification**: Always run `npm run build` after modifying dependencies or TypeScript code to ensure types and bundle pass without error.
- **Node.js Environment**: The project runtime is pinned to Node.js `26.8.2` (configured via `.nvmrc` and `package.json` engines).
- **Code Quality**: Run `npm run lint` (`oxlint`) to maintain code cleanliness.
